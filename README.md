# 🚀 Prem Kumar | Personal Portfolio

A modern, interactive and responsive personal portfolio website developed using **Python, Django, HTML, CSS and JavaScript** to showcase my professional profile, technical skills, projects and development journey.

🌐 **Live Demo:** https://prem-portfolio-main.onrender.com

## 📌 About the Project

This portfolio serves as my personal digital identity, providing a central place for recruiters, developers and visitors to explore my technical background, academic projects, skills and achievements.

The website combines Django backend functionality with a customized, cinematic frontend design to create an engaging browsing experience.

## ✨ Key Features

- **Home:** Professional introduction and personal profile.
- **About Me:** Educational background and career interests.
- **My Projects:** Showcase of academic and personal projects.
- **Technical Skills:** Programming languages, web technologies, databases and AI/ML tools.
- **My Journey:** Education, training, certifications and achievements.
- **Resume:** Option to access and download my resume.
- **Contact Me:** Contact section with an interactive message form.
- **Interactive UI:** Animated elements, project cards and responsive navigation.
